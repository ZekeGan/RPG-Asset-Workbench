## 只讀代碼觀察（不是修復結果）

H-B05：operations.ts 的 pending 使用 active !== null && active !== deployed；renderer 的列表篩選與操作頁也要求 active 存在。會漏掉 active=null、deployed=V1 的回原圖。不能只改 UI，必須涵蓋預檢、寫入、日誌／回滾、部署 metadata 與列表狀態。尚未為新修正增加／執行測試。

H-B16：batch.ts 現在比對 pngPath(asset.path) === 匯入相對路徑；沒有 basename 唯一檔名 fallback。這是可見差距，不代表已完整重現「第一次」時序錯誤；後續要同時測初次輸入及不同選擇資料夾層級。

H-B18：relink 要求候選路徑集合與資料庫 assets 完全一致，並檢查設定 hash/key 和部署內容。失敗後不更新 root 是保護行為。實際使用者遊戲、掃描完成度、大小寫、檔案增減等未知，尚未判定根因；不得移除一致性檢查來消除錯誤。
