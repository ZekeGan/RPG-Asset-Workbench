## 工程待查，不要當成需要使用者重做需求決策

- 本機 Git repository／遠端／分支／手動改動均未知。先 git status、remote -v 等只讀確認；本包不建立或推送。
- 重新連結 bug 的實際差異：需要使用者環境中逐路徑診斷，避免索取整套私人遊戲或金鑰。
- 名稱配對大小寫、Unicode、加密副檔名正規化與多候選要測；沒有核准可以模糊猜測。
- 不完整專案搬家後的重新連結與續掃要協調；不可用只比部分已掃清單阻擋所有合理搬移，也不可跳過已保存基準驗證。
