# RPG Asset Workbench（R-aW）

<img src="../../resources/icon.png" alt="R-aW" width="96" height="96" />

[繁體中文](../../README.md) · [简体中文](README.zh-CN.md) · 日本語 · [English](README.en.md)

Windows で RPG Maker MV／MZ（RPGツクール MV／MZ）の画像差し替えを管理するツールです。元画像を固定バックアップとして保存し、差し替え版のプレビュー、一括対応付け、確認後の適用と復元を行えます。

現在のソースコードのバージョンは **0.5.5** です。1.0 の公開準備中であり、公開済みではありません。対象は Windows x64 です。最低対応 Windows バージョンと ARM64 は未検証です。

## ダウンロードと起動

公開後、このリポジトリの **Releases** ページから Windows x64 用の配布 ZIP をダウンロードしてください。GitHub の「Source code」ZIP はソースコードで、そのまま実行できるアプリではありません。配布ファイルがない場合、ダウンロード版はまだ提供されていません。

ZIP の**全ファイルを展開**し、書き込み可能なフォルダー内の `RPG Asset Workbench.exe` を起動します。同梱ファイルを残し、EXE だけを移動したり、ZIP 内から直接起動したりしないでください。配布版に Node.js の別途インストールは不要です。

## 使い方

1. まずゲームを別途バックアップします。初回は信頼できる未変更のゲームコピーを選び、元画像の基準を保存します。
2. ホーム画面でプロジェクトを作成し、ゲームの場所を指定してスキャン完了を待ちます。キャンセルしても進捗は保存され、再開できます。未完了の状態では適用できません。
3. ワークベンチで検索、元フォルダーの閲覧、カスタムグループの作成を行います。元画像と差し替え画像はクリックで拡大できます。
4. 静止 PNG を1枚、対象素材の差し替え欄へドロップし、確認して取り込みます。複数枚では一括対応付けが開きます。候補が複数ある場合は手動で指定し、確定前に対象を確認してください。
5. バージョンの選択だけではゲームに書き込みません。「ゲームに適用」で確認した後に書き込みます。ゲーム内で表示結果を確認してください。
6. 元画像の選択も、適用の確認が必要です。必要に応じて復元機能を使用します。バージョン履歴は残ります。

ホームの言語アイコンで繁体字中国語、簡体字中国語、英語、日本語を切り替えられます。プロジェクト設定では名前、カバー、ゲームの場所の再リンクを変更できます。グループの名前変更や素材の追加・解除も可能です。

## データ、バックアップ、削除

- ツールのデータは Windows ユーザーのアプリケーションデータ領域に別途保存されます。すべてが EXE の隣にあるわけではなく、展開して起動できる ZIP でも、データがアプリのフォルダーと一緒に移動するとは限りません。
- 更新前にアプリを終了し、ゲームとツールのデータディレクトリ全体をバックアップして、新版を別フォルダーに展開します。以前のプロジェクトが表示されない場合は操作を止めて報告し、再作成や旧データの削除をしないでください。
- **プロジェクトの完全削除は、ツール内の元画像バックアップ、差し替え版、関連データを削除します。ツールによる復元ができなくなります。ゲームは削除時の画像のままで、自動復元されません。** 元画像に戻したい場合は先に復元して確認してください。
- グループや所属素材の解除は分類上の関連だけを削除します。適用待ちの取り消しとバージョン削除は別操作です。元画像と適用済みバージョンは個別削除できません。
- 展開したアプリのフォルダーを削除しても、ツールのデータは消えません。復元が必要な間はデータディレクトリを削除しないでください。

## 対応範囲と制限

- MV／MZ の非暗号化画像および標準の画像暗号化が対象です。独自暗号化や改変エンジンへの対応は保証しません。
- 静止 PNG のみ。JPEG、APNG、偽装拡張子は受け付けません。1ファイルの上限は 32 MiB です。
- 通常の上限は 16,777,216 ピクセルです。差し替え／一括取り込みでは確認後に大きな画像を処理でき、最大 33,554,432 ピクセルです。元画像のスキャンとカバーは通常の上限のままです。
- 差分スキャンは確認した新規パスのみ追加し、元画像の基準を上書きしません。移動したゲームは再リンクできます。オフラインでは保存データを閲覧できますが、ゲームには書き込めません。
- 外部変更との競合時は適用／復元を中止します。強制上書き機能はありません。失敗時は画面の復旧案内に従い、バックアップとエラー情報を保管してください。
- クリーンな Windows、最終配布物、更新時の互換性には未検証項目があります。すべてのプラットフォーム検証が完了した 1.0 正式版ではありません。
