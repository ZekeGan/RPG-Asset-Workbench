## 功能摘要

- 回原圖待套用、續掃與增量掃描、離線／重新連結及批量配對。
- 專案封面／改名／刪除、群組選圖、側欄收合、快捷版本操作及歷史縮圖。
- 四語介面、R-aW 品牌、單張拖放確認、多張批量分流、圖片放大與受控大圖匯入。
- 修正外層捲動溢出，統一應用內捲軸。
