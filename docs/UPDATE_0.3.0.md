# 0.3.0 開發測試版

2026-10-22。MVP 尚未完成。本次延續已批准的實作，不改 PRD 的功能與安全規則。

## 本次可操作功能

- 保留 0.2.0 未加密 MV/MZ 掃描、固定原始備份、專案切換及素材清單。
- 詳細頁匯入靜態 PNG，顯示尺寸、比例及透明能力差異，需接受才能保存；保存原始上傳位元組。
- 每張素材版本獨立遞增，選用、取消選用、歷史刪除保護；選用與部署分離。歷史預覽不變更選用。
- 單張及目前範圍／全專案匯出，選原圖或目前版本，無選用回退原圖；同名取消／略過／覆蓋，逐檔回報。
- 未加密遊戲套用全部 pending、部分／全部還原；備份與外部變更檢查、寫後驗證、操作日誌、失敗恢復。
- 開啟專案時發現未完成操作，顯示恢復頁；由使用者確認恢復，未完成前阻擋匯入／選用／刪版本／新套用。

對應 FR-007/008/009/011/014/015/017/018/019/020/021/022 的實作子集，SCREEN-004/006/007/009/011/012/014。不是這些 FR 的完整驗收。

## 更新與啟動（Windows）

先關閉舊程式。將本包解壓至另一個資料夾，不要把 node_modules 或遊戲素材混入。
資料庫仍使用相同 Electron userData，啟動會以新增資料表擴充，不清除原始基準。
更新前可複製整個工具 userData 為保險備份；不要在程式執行時複製 SQLite 單一檔案。

在本包的 rpg-image-tool-poc 資料夾依序執行：

```powershell
npm ci
node node_modules/electron/install.js
npm run typecheck
npm test
npm run native:electron
npm run dev
```

已安裝的 Visual Studio C++ Build Tools 與 Python 可沿用。
`npm test` 使用 Node ABI，`npm run dev` 使用 Electron ABI；若之前重建為 Electron，要先 `npm run native:node` 才能重跑測試。
此包沒有 Windows exe；原生套件及本版畫面仍需 Windows 實測。

## 請在可拋棄測試副本驗證

1. 用未加密 MV、MZ 各一份乾淨副本建立專案，檢查素材清單與原圖。
2. 詳細頁匯出一張原圖，在外部修改後匯入；不同尺寸時先取消，再接受一次。
3. 關閉重開，確認歷史及選用存在。切換歷史／取消選用，遊戲圖片此時應未改變。
4. 選用修改版，關閉遊戲，於工作臺按「套用／恢復」，核對完整清單與遊戲路徑後確認。
5. 開遊戲確認圖片。再關閉遊戲，從「還原」選取該圖並確認；開遊戲檢查原圖回來，歷史仍保留。
6. 另用測試副本，在工具外修改某目標圖片，再套用；應阻擋，不能覆蓋未知外部修改。
7. 匯出到獨立空資料夾，再次匯出測試同名取消／略過／覆蓋。不可選遊戲或工具資料目錄。

不要在唯一遊戲副本人工強制終止。自動測試已使用自製資料執行程序中斷，不需要你在私人遊戲做破壞性測試。
回報請包含版本 0.3.0、MV 或 MZ、操作步驟、畫面錯誤全文。

## 測試證據與限制

詳見 TEST_REPORT.md 的 0.3.0 節。自製三張素材的實際檔案測試確認：匯入不寫遊戲、套用只改目標、還原回原始位元組、第二次套用失敗回前一次部署、恢復可重試、未知外部變更阻擋。
真正子程序 exit(77) 模擬程序突然退出，涵蓋寫入意圖後、第一檔後、全部檔案寫完但部署提交前。不是斷電、磁碟裝置故障或 Windows 檔案占用的替代測試。
檔案 rename 與外部程式仍有競態窗口；未宣稱 OS 全域排他。目錄落盤／突然斷電、Windows 占用、磁碟滿實機仍待驗證。
