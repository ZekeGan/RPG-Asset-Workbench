## 本輪實作

- 首頁提供繁體中文、簡體中文、English、日本語，保存語言偏好；切換後重新載入首頁，同步主程序原生對話框語言。使用者專案／群組名稱與檔案路徑保持原樣。
- 共用翻譯字典涵蓋介面、確認框、程式可辨識的錯誤與圖片差異提示；未知系統診斷保留原文。簡體字映射為靜態檔案，無額外執行期依賴。
- Header 顯示 R-aW，品牌不再作為返回首頁按鈕；視窗標題 R-aW — RPG Asset Workbench。打包產品名稱更新，套件 name、appId 及作者保持不變。介面版號由 package.json 讀取，目前仍為 0.4.0，下一個正式版號待定。
- 工作臺原圖及目前選用的替換圖片可直接點擊放大；標題顯示版本資訊。
- 單張外部檔案拖到指定列的替換欄，開啟上傳確認框；確認後才建立版本，取消不保存、不寫遊戲。單張拖到其他位置給出放置提示；多張拖到工作臺（包括替換欄）進入批量配對。
- 批量來源預覽獨立於配對狀態，未配對／多候選也可看縮圖與放大。懶載入預覽避免一次保留全批圖片；每次讀取核對預檢 hash，來源變動時拒絕使用。
- 替換圖片與批量匯入的一般門檻為 16,777,216 像素；超過門檻先提示，確認後才解碼。硬上限為 33,554,432 像素，檔案上限仍為 32 MiB。處理逐張排隊，縮圖直接由解碼管線產生，避免先建立額外完整 RGBA 副本；保存的替換原檔位元組不變。大圖同意與預檢檔案綁定，匯入提交再次驗證。遊戲原圖掃描與專案封面仍使用一般門檻，本輪不默默放寬其他來源限制。

## 驗證狀態

- typecheck、完整 7 檔 86 項測試及 build 通過。含既有安全回歸、四語字典／插值／錯誤提示、未配對與多候選預覽、來源變更阻擋、大圖同意與原檔保存。
- 大圖測試使用自製 PNG：4097×4096 驗證一般門檻外需同意，8192×4096 驗證硬上限內可處理；8193×4096 在解碼前拒絕。這是邊界驗證，不代表所有硬體與所有圖像內容都具有相同耗時／記憶體需求。
- 更新簡體字映射後，針對性 4 項 i18n 測試再次通過；沒有重跑無關完整回歸。
- Windows Electron 隔離 UI 驗收通過：四語首頁／工作臺／設定、偏好保存、原生警告文字、錯誤翻譯、使用者名稱保持原樣；單張確認／取消、多張分流、未配對預覽、列表放大與遊戲內容不變。結果見 [feature-checks.json](evidence/languages-drag/feature-checks.json)，同目錄保存截圖。使用實際 main/preload/renderer、File 物件及 DOM 拖放事件；原生對話框使用替身，測試視窗離屏繪製。人工選檔、作業系統真實拖曳手勢及 MV/MZ 真實遊戲四格仍不視為通過。
- 畫面檢查修正窄視窗日文工具列換行重疊，以及英文頁數缺少空格；只追加受影響的字典／建置／UI 檢查。本輪修改程式檔案 Prettier 檢查通過。
